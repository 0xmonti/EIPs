## 1. System Overview

`0xmonti.net` utilizes **EIP-1014 (CREATE2)** at opcode `0xf5` to enable deterministic, counterfactual address generation. This architecture allows `[https://eip-monti.ai.studio](https://eip-monti.ai.studio)` to interact with off-chain contract addresses prior to on-chain execution, ensuring that contracts deployed across `0xmonti.net` are cryptographically bound to exact initialization bytecodes, cell coordinates, and `MontiOAT` verification payloads.

---

## 2. Address Derivation & Gas Specification

### 2.1 Cryptographic Address Formula

The address calculation for all counterfactual nodes deployed on `0xmonti.net` uses a fixed 85-byte preimage hash:

$$\text{Address} = \text{Keccak256}\left(\text{0xff} \parallel \text{sender} \parallel \text{salt} \parallel \text{Keccak256}(\text{init\_code})\right)[12..31]$$

* `0xff`: 1-byte constant disambiguator (`0x80` to `0xff` prefix prevents collision with RLP `keccak256(rlp([sender, nonce]))`).
* `sender`: 20-byte deploying contract address (`0xmonti.net` Factory or Enclave).
* `salt`: 32-byte caller-provided identifier (e.g., cell hash or session nonce).
* `init_code`: Runtime creation bytecode containing constructor arguments.

### 2.2 Gas Execution Schedule

Total gas for opcode `0xf5` is calculated prior to memory evaluation or contract initialization:

$$\text{Gas}_{\text{Total}} = \text{Gas}_{\text{Create}} + \text{Gas}_{\text{MemoryExpansion}} + \left( G_{\text{sha3word}} \times \left\lceil \frac{\text{len}(\text{init\_code})}{32} \right\rceil \right)$$

| Gas Component | Cost (Gwei / Units) | Description |
| --- | --- | --- |
| `CreateGas` | 32,000 gas | Base contract creation fee |
| $G_{\text{sha3word}}$ | 6 gas per word | Hashing cost for `init_code` payload |
| Collision Handling | Immediate Revert | Reverts if target address has non-zero `nonce` or non-empty `code` (EIP-684) |

## 3. Direct Brain Payload & MontiOAT Integration

`[https://eip-monti.ai.studio](https://eip-monti.ai.studio)` encodes active verification signatures directly into the `salt` and constructor arguments during `CREATE2` execution.

### 3.1 Verification Payload Schema

```json
{
  "action": "verify_signature",
  "tokenType": "MontiOAT",
  "cell": {
    "row": 0,
    "col": 0
  },
  "timestamp": 1711929600
}

```

### 3.2 Cell-Bound Salt Generation

To bind `MontiOAT` cell coordinates `(0, 0)` directly to the counterfactual address, the 32-byte `salt` is derived as follows:

$$\text{salt} = \text{Keccak256}(\text{abi.encode}(\text{"MontiOAT"}, \text{row}=0, \text{col}=0, \text{timestamp}=1711929600))$$

## 4. `eip-monti.ai.studio` Factory Implementation

The following EVM implementation demonstrates counterfactual instantiation and direct payload signature verification for `0xmonti.net`:

```solidity
// SPDX-License-Identifier: MPL-2.0-monti
pragma solidity ^0.8.25;

contract MontiStudioFactory {
    event NodeDeployed(address indexed nodeAddress, bytes32 indexed salt, bytes32 payloadHash);

    struct Cell {
        uint256 row;
        uint256 col;
    }

    /// @notice Computes deterministic address prior to deployment
    function computeNodeAddress(
        address deployer,
        bytes32 salt,
        bytes memory initCode
    ) public pure returns (address nodeAddress) {
        bytes32 hash = keccak256(
            abi.encodePacked(
                bytes1(0xff),
                deployer,
                salt,
                keccak256(initCode)
            )
        );
        return address(uint160(uint256(hash)));
    }

    /// @notice Deploys counterfactual contract via CREATE2 (0xf5) and validates MontiOAT payload
    function deployBrainNode(
        uint256 row,
        uint256 col,
        uint256 timestamp,
        bytes memory initCode
    ) external payable returns (address nodeAddress) {
        // Derive salt from MontiOAT verification payload
        bytes32 salt = keccak256(abi.encodePacked("MontiOAT", row, col, timestamp));

        assembly {
            // CREATE2 opcode (0xf5): endowment, memory_start, memory_length, salt
            nodeAddress := create2(callvalue(), add(initCode, 0x20), mload(initCode), salt)
            if iszero(extcodesize(nodeAddress)) {
                revert(0, 0)
            }
        }

        emit NodeDeployed(nodeAddress, salt, keccak256(abi.encodePacked(row, col, timestamp)));
    }
}

```
